Таблиці, графіки, знімки екрана й схеми для диплома. Числа взято з фінального прогону
`scripts.evaluate` від 17.11.2026 (повна сітка, 200 користувачів через Qwen3 на домен);
сирі файли звіту — у [data/](data/).

Схеми розраховано на вставлення на ширину сторінки 16,5 см: полотно 1000 px, основний текст 21 px
(≈ 9,8 пт), заголовки 24 px (≈ 11 пт), моноширинні підписи 18–19 px (≈ 8,5–9 пт). Для Word краще
вставляти SVG (масштабується без втрат); PNG відрендерено з подвоєною щільністю. Графіки збережено
з 200 dpi; після змін у `draw_charts` їх можна перемалювати командою
`docker compose exec api python -m scripts.evaluate --redraw`.

## Протокол експерименту

- Релевантні об'єкти: явна оцінка ≥ 8 за шкалою 1–10 у відкладеній частині; неявні взаємодії лише в навчанні.
- Валідація й тест — по 10 % взаємодій кожного користувача; MovieLens — за часом, Book-Crossing — випадково (`seed=42`).
- Гіперпараметри обрано за NDCG@10 на валідації; фінальні моделі перенавчено на навчальній і валідаційній
  частинах і перевірено один раз на тесті.
- Холодний старт: природний (< 10 взаємодій у навчанні) та імітований (історію кожного тестового користувача
  обрізано до 5 взаємодій).
- Покриття@10 — частка каталогу, що потрапляє хоча б в один top-10.

## Висновки з експериментів

1. **Гібридизація працює на повних історіях в обох доменах.** Зважений гібрид має найкращий NDCG@10:
   +3 % до ALS на MovieLens (0.0962 проти 0.0934) і +8 % на Book-Crossing (0.0549 проти 0.0508).
2. **Гібрид розширює покриття каталогу.** На книгах Coverage@10 зростає з 0.053 (ALS) до 0.248, тобто
   рекомендації охоплюють у 4,7 раза більше книг і водночас точніші.
3. **Холодний старт залежить від домену.** На книгах, де контентна модель сильніша, найкращий RRF:
   +30 % NDCG@10 до ALS на природному зрізі, +21 % в імітації. На фільмах за п'яти оцінок ALS
   лишається найкращим, а зважений гібрид поступається, бо при малій історії його вага зсувається
   на слабшу тут контентну модель.
4. **Qwen3 як переранжувальник:** на фільмах +3 % NDCG@10 (0.0875 → 0.0901), на книгах −8 %
   (0.0766 → 0.0702). Метадані книг бідні (назва, автор, видавець), і модель переставляє кандидатів
   за поверхневими ознаками. Основна цінність LLM — пояснення українською; усі 400 викликів
   завершилися без відмов і таймаутів.
5. **Контентна модель окремо слабка** (NDCG@10 0.024–0.026), але дає найбільше покриття (≈ 0.31)
   і є основним сигналом для нових користувачів.
