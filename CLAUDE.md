# Правила проєкту

Гібридна рекомендаційна система (фільми + книги): ALS + контентні ембединги BGE-M3 + локальна LLM Qwen3 8B через Ollama. Дипломний проєкт.

**Джерело істини — `docs/IMPLEMENTATION.md`.** Перед будь-якою роботою прочитай його. Реалізація йде етапами з розділу 10; виконуй лише той етап, який названо в запиті, і наприкінці пройди його критерії приймання, показавши результат кожної перевірки.

## Незмінні рішення

- Жодних платних або хмарних API. LLM і ембединги — тільки локальний Ollama (`qwen3:8b`, `bge-m3`).
- Python-код запускається лише в контейнері `api` (`docker compose exec api ...`), не на Windows-хості.
- Ollama працює на хості; з контейнера — `http://host.docker.internal:11434`.
- Жодних bind-монтувань теки проєкту в `docker-compose.yml` (шлях задовгий для Docker Desktop). Лише іменовані томи; код потрапляє в контейнер через образ або `docker compose watch`. Перед `docker compose exec api ...` після змін у коді: `docker compose up -d --build api`, якщо `watch` не запущено.
- Порти на хості беруться з `.env` (`WEB_HOST_PORT`, `API_HOST_PORT`, `DB_HOST_PORT`); не вписуй 3000/8000 у команди перевірки — читай їх із `.env`.
- Браузер звертається тільки до Next.js; `/api/*` проксіюється на FastAPI. Фронтенд не викликає Ollama.
- Оцінки в базі — єдина шкала 1–10.
- Код у `backend/app/recsys/` не залежить від FastAPI; ним користуються й ендпоінти, і скрипти оцінювання.
- Відповіді LLM завжди перевіряються кодом; за будь-якої помилки моделі користувач отримує гібридний список без пояснень.
- Експерименти: ALS навчається лише на навчальній частині розбиття; фіксований `seed=42`.

## Робочі домовленості

- Якщо специфікація розходиться з реальністю (API бібліотеки, формат датасету, параметр Ollama) — перевір актуальну документацію, зупинись і повідом; не обходь мовчки.
- Якщо змінюється архітектурне рішення — онови `docs/IMPLEMENTATION.md` у тій самій зміні.
- Мова інтерфейсу, пояснень LLM і документації — українська. Ідентифікатори та коментарі в коді — англійською.
- Backend: `ruff` + `pytest`; анотації типів обов'язкові. Frontend: TypeScript `strict`, `npm run lint`.
- Не коміть `data/`, `backend/artifacts/`, `.env`.
- Не додавай залежностей, яких немає в специфікації, без пояснення навіщо.
